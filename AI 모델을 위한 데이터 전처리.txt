1. 불필요 데이터 필터링
- "매매", "보증금/월세", "LH 전세임대", "복층여부", "현관유형", "총 세대수", "준공인가일" 등 전세사기 위험도 측정을 위한 모델 학습의 불필요 컬럼 제거
- 전세 가격이 존재하지 않는 데이터 필터링
- 필드 데이터가 결측인 데이터 제거

2. 데이터 파싱 및 구조화
- "전용/공급면적" 항목에서 전용 면적만 추출하여 float으로 변환 후, 평 단위(전용면적_평)로 재계산
- "방 수/욕실 수" -> 각각 분리하여 정수형으로 변환
- "해당층/건물층" -> 정수형으로 파싱 후 비율 기반으로 층등급 산정

3. 금액 필드 처리
- "월세보증금", '월세가격', '관리비' -> 텍스트 내 숫자만 추출하고 단위 변환(만원 -> 원)
- '전세' -> "1억2000" 형태도 파싱하여 정수(원 단위)로 환산
- 전세가 없는 경우 전월세 환산식: 월세보증금 + (월세가격 * 12 / 0.07) 을 이용해 전세추정가 계산
- 최종적으로 전세추정가를 전세 컬럼으로 저장하고 원 단위 기준으로 백만원 단위 반올림

4. 이진 변수 및 범주형 변수 인코딩
- '주차가능여부' : "세대 당 0.7 이상" -> 1, "세대 당 0.7 이하" -> 0
- '즉시입주여부' : "즉시 입주" -> 1, 아니면 -> 0

5. 건물 노후도
- '사용승인일'을 기준으로 연차 계산 (2026년 2월 5일 기준)
- 연차 점수 (건축 점수) :
  -> 0~5년 : 1.0 (신축)
  -> 6~15년 : 0.5 (준신축)
  -> 16년 이상 : 0.0 (노후)

6. 건축물용도 기반 보증보험 점수
- 점수 기준 :
  -> 공동주택 : 1.0
  -> 단독주택 : 0.3
  -> 업무시설 : 0.1
  -> 그 외(숙박, 공장, 미등기건물, 근린생활시설 등) : 0.0

7. 옵션 점수화 (roomTitle)
- 옵션 항목에 포함된 키워드를 기반으로 점수 계산
- 점수 기준 :
  -> 1.0점 : 냉장고, 세탁기, 가스레인지, 전자레인지, 싱크대
  -> 0.8점 : 침대, 건조기
  -> 0.6점 : 옷장, 신발장, 벽걸이형 에어컨
  -> 0.5점 : 책상, 식탁, 샤워부스, 붙박이장, 스탠드형 에어컨
  -> 0.4점 : 인덕션, 욕조, 천장형 에어컨, 베란다
  -> 0.3점 : 쇼파, 마당, 무인택배함, 가스오븐, 식기세척기, TV
  -> 0.2점 : 화재 경보기
- 여러 옵션이 포함되면 점수 합산하여 최대 10점 기준으로 반영

8. 방향 점수화
- 점수 기준 :
  -> 남(5.0) / 남동(4.5) / 남서(4.0) / 동(3.5) / 서(3.0) / 북동(2.5) / 북서(2.0) / 북(1.5)

9. 지역 특색에 맞는 데이터 이용
- 부동산 실거래가를 이용한 동별 평당평균 전세가
- 동별 총인구수
- 동별 평균연령
- 동별 토지 평균평당가격
